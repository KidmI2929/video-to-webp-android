## v1.1 Mobile UI

- 모바일 단일 장문 스크롤 UI를 **편집 / 추적 / 출력 / 결과** 4개 하단 탭으로 재구성
- 변환 실행/취소 버튼과 진행률을 하단에 고정해 어느 탭에서도 즉시 접근
- 상단에 해상도 / FPS / 품질 / 화면비 / 추적 / 분할 상태 요약 칩 표시
- 편집 탭: 영상 플레이어, 프레임 이동, IN/OUT 트림에 집중
- 추적 탭: 작은 전용 미리보기 + 화면비 / 고정·얼굴·상체·전신 추적 설정
- 출력 탭: 프리셋 / 화질 / 저장 위치 / 분할 설정만 표시
- 결과 탭: 변환 완료 시 자동 이동, 미리보기 / 개별·전체 공유 집중
- 시스템/라이트/다크 테마 전환을 콤팩트 헤더에 유지
- 기능이 늘어나도 각 탭 내부에서만 확장하도록 구조를 변경해 전체 페이지 스크롤 길이 감소

## v1.0

- 모바일 Android판 인물 추적 크롭 완성
- 고정 / 얼굴 / 상체 / 전신 추적 모드
- 얼굴 모드: 여러 얼굴 중 탭 위치에 가까운 얼굴을 우선 선택하고 tracking ID로 이어서 추적
- 상체 모드: 머리·어깨·팔·골반 포즈 중심 추적
- 전신 모드: 머리부터 발까지 포즈 랜드마크를 사용한 전신 중심 추적
- 추적 위치 저역통과 스무딩 + 급격한 이동 제한 + 미검출 구간 직전 위치 유지
- 포즈 검출 실패 시 얼굴 위치 보조, 전체 추적 실패 시 기존 고정 포커스로 자동 fallback
- 얼굴/포즈 모델은 앱에 번들되어 추적 분석에 인터넷 업로드를 사용하지 않음
- 추적 모드·화면비·기준 포커스 자동 저장
- 기존 터보 변환, 프레임 단위 플레이어, 저장 폴더, 개수/용량 분할, 라이트/다크 모드 유지

> 상체/전신 추적은 ML Kit Pose Detection의 가장 두드러진 인물을 대상으로 합니다. 여러 인물을 동시에 독립 추적하는 기능은 포함하지 않습니다.

# Motion WebP — Video → Animated WebP

Android에서 영상을 확인하고 원하는 구간을 잘라 **Animated WebP**로 빠르게 변환하는 로컬 앱입니다.

## v0.6

### 새 UI / 플레이어
- Material 3 기반 새 디자인, 라이트/다크 모드 대응
- AndroidX Media3 / ExoPlayer 기반 영상 미리보기
- 재생 / 일시정지, ±1초 이동
- 선택한 IN/OUT 구간만 반복 확인
- 트림 RangeSlider를 움직이면 플레이어가 해당 위치로 즉시 seek
- 현재 선택 구간의 재생 진행률 표시

### 저장 폴더
- Android 시스템 폴더 선택기(SAF) 사용
- 사용자가 원하는 폴더를 선택해 WebP 저장
- 선택한 폴더 권한을 유지해 다음 실행에서도 재사용
- 기본값은 Pictures/VideoToWebP

### 분할 생성
- 분할 없음
- 개수 기준: 선택 구간을 2~20개의 동일 시간 파트로 생성
- 용량 기준: 파일당 목표 MB를 기준으로 구간 길이를 자동 조정
- 용량 분할은 WebP를 정상적으로 끝까지 인코딩한 뒤 실제 파일 크기를 측정하고 재조정하므로 단순 바이트 절단 방식처럼 깨진 WebP를 만들지 않음
- 콘텐츠 복잡도와 WebP 특성 때문에 목표 MB는 정확한 상한이 아니라 근사 목표값

### 변환
- MP4 / MOV / WebM 등 FFmpeg가 읽을 수 있는 영상
- 원본 / 1080 / 720 / 480 / 320 최대 변 해상도
- FPS 5–30
- 품질 10–100
- Lossy / Lossless
- 무한 반복 / 1회 재생
- 빠름 / 균형 / 최대 압축
- 진행률 / 취소
- 결과 Animated WebP 미리보기
- 여러 파트 결과 목록 및 전체 공유
- 서버 업로드 없이 기기 내부 처리

## 엔진

GitHub Actions에서 앱 전용 ARM64 FFmpegKit AAR을 직접 빌드합니다.

- --enable-libwebp
- --enable-mediacodec
- ARM64 / NEON
- FFmpegKit --speed 빌드
- SAF URI 직접 입출력
- libc++_shared.so 포함 검증
- APK 내부 libwebp 설정 재검증

## 지원

- Android 10 (API 29) 이상
- arm64-v8a
- compileSdk 36 / targetSdk 35

## APK

GitHub **Actions → Build Android APK → 최신 성공 빌드 → Artifacts → MotionWebP-v1.1-mobile-ui-apk** 에서 받을 수 있습니다.
